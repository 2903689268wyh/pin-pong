# pin-

剪辑得分软件。在浏览器里给一条成片打分，把问题记在时间线上，再导出或打印评分单。

评分存在本机 `localStorage`，视频只用于本地预览，不会上传。

## 使用

用浏览器打开 `index.html` 即可。页面不依赖构建工具，也不需要网络。

1. 左侧选择成片，或点「新建成片」。第一次打开会有一条示例，方便直接看评分单长什么样。
2. 「选择视频」后可以边看边记。刷新之后需要重新选文件，时间线笔记仍会留下。
3. 右侧七个维度各 0–10 分，默认权重加起来是 100。总分是加权百分制。
4. 时间线接受秒（`75`）或分:秒（`1:15.5`）。有视频时可以「取当前时间」。
5. 「导出 JSON」可以带走评分单，「导入 JSON」可以再读回来。「打印评分单」走浏览器打印。

等级：90 分及以上 S，80 A，70 B，60 C，其余 D。

## 测试

计分和时间码的规则在 `js/score.js`，测试不需要浏览器：

```bash
node --test test/score.test.cjs
```
